# 示例项目提示词

首页输入框最多 500 字，对话页最多 1000 字。下列提示词均可直接粘贴使用。

建议：未指定生成类型时，带「Vue3 / 多页面 / 后台」的会走 Vue 工程，展示型站点走多文件或单 HTML。

---

## 1. 波普风电商品牌页

**推荐类型**：多文件模式  
**首页标签**：波普风电商页面

```
做一个波普风潮流电商品牌官网。视觉：亮黄、洋红、纯黑强撞色，粗描边、半调网点、漫画爆炸框和手写标语。页面含顶部导航（Logo、新品、系列、关于、购物袋）、全屏海报轮播、当季热卖 6 件商品卡片（图片、名称、价格、「加入购物袋」）、品牌故事、页脚订阅。点击商品弹出简易详情浮层，购物袋可加减数量。必须响应式，图片用占位图，交互用原生 JS，不要登录和后台。
```

## 2. 科技企业官网

**推荐类型**：多文件模式  
**首页标签**：企业网站

```
做一个面向 B 端的科技公司官网，深空蓝配电光青，干净现代。包含顶部导航（产品、解决方案、客户案例、关于我们、联系我们）、Hero 大标题与「预约演示」按钮、三块核心产品介绍、客户 logo 墙、三则案例卡片、团队简介、底部联系表单（提交后前端提示成功）。滚动有轻微入场动画，必须响应式，不要后台系统。
```

## 3. 电商运营后台

**推荐类型**：Vue 工程模式  
**首页标签**：电商运营后台

```
用 Vue3 做一个电商运营后台，侧边栏+顶栏布局。页面：登录页（任意账号可进入）、数据概览（今日订单、销售额、待发货、退款，以及用 CSS 模拟的简易柱状图）、商品管理（表格含图、名称、价格、库存、上下架，支持搜索和新增弹窗）、订单列表（状态筛选：待付款/待发货/已完成）。全部 mock 数据，hash 路由。风格浅蓝灰企业风，表格清晰，不要真实后端。
```

## 4. 暗黑话题社区

**推荐类型**：Vue 工程模式  
**首页标签**：暗黑话题社区

```
用 Vue3 做一个暗黑风格话题社区。深黑背景、紫红强调色、卡片微光边。页面：信息流首页（帖子卡片含头像、标题、摘要、点赞与评论数）、帖子详情（正文、评论列表、发表评论）、话题广场（标签云，点击筛选）、个人主页（我的帖子）。顶部导航含搜索。mock 至少 10 条帖子。hash 路由，无需登录后端。
```

## 5. 个人技术博客

**推荐类型**：Vue 工程模式

```
用 Vue3 做一个个人技术博客。页面：首页（文章卡片列表、分类筛选、关键词搜索）、文章详情（标题、日期、标签、正文排版）、关于我。顶部导航，底部版权。本地 mock 至少 8 篇文章。风格极简白底、衬线标题、阅读舒适、响应式。hash 路由，不要后端。
```

## 6. 设计师作品集

**推荐类型**：HTML 模式

```
做一个设计师个人作品集单页。深色背景、大号无衬线标题、大量留白。区块：姓名与一句话介绍、技能标签、精选作品网格（至少 6 项，点击放大预览）、工作经历时间线、联系方式与邮箱表单（提交前端提示）。滚动平滑，移动端适配，图片用占位图。
```

## 7. 独立咖啡店点单页

**推荐类型**：HTML 模式

```
做一个独立咖啡店宣传兼点单落地页。暖木色+奶油白，手写感标题。Hero 展示店名与营业时间；招牌饮品 8 款（图、名称、价格、「加入购物车」）；右侧购物车可加减数量并计算总价；门店地址、地图占位、预约到店表单。移动端优先，交互用原生 JS，不要后台。
```

## 8. 在线课程平台

**推荐类型**：Vue 工程模式

```
用 Vue3 做一个在线课程平台前台。页面：首页（banner、热门课程 8 门、分类入口）、课程列表（分类与价格筛选）、课程详情（大纲、讲师介绍、报名按钮）、学习中心（我的课程与进度条）。风格白底靛蓝主色、大圆角卡片。全部 mock 数据，hash 路由，无需登录后端。
```
